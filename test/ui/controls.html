Each box names the element, the data-gtw-* attribute and the value under test. The guard is injected by the harness/preview.

Checkbox

#cb_before · data-gtw-auth="before" · check → login; uncheck → free (no login).

#cb_after · data-gtw-auth="after" · check → login + checked; uncheck → free.

Radio

#r_a / #r_b · data-gtw-auth="before" on each radio · select B → login; click the already-selected A → free.

#rl_a_label / #rl_b_label · data-gtw-auth="before" on the label · same behaviour, attribute on the label.

Select

#sel_before · data-gtw-auth="before" · data-gtw-auth-off="" · click = open for free; change to A/B → login + revert to “Off”.

#sel_after · data-gtw-auth="after" · data-gtw-auth-off="" · change to A → login + value kept.

#sel_default · data-gtw-auth="before" · no data-gtw-auth-off → OFF = default value x · change to Y → login + revert to X.

#sel_override · data-gtw-auth="before" · data-gtw-auth-off="y" (default x) · Y = free; X = activation → login + revert to Y.

#sel_for_label · data-gtw-auth="before" on the label[for] · #sel_for · data-gtw-auth-off="" · label click free; change → login + revert to “Off”.

#wrap_sel · data-gtw-auth="before" + data-gtw-auth-off="" on a wrapper · #wsel · click free; change → login + revert to “Off”.

Range and date

#range_before · data-gtw-auth="before" · data-gtw-auth-off="0" · click free; change to 5 → login + revert to 0.

#range_default · data-gtw-auth="before" · no data-gtw-auth-off → OFF = default value 5 · change to 7 → login + revert to 5.

#date_before · data-gtw-auth="before" · data-gtw-auth-off="" · click free; pick a date → login + revert to empty.

Details

#det_before · data-gtw-auth="before" · closed → open = login; open → close = free.

Details before

Body

#det_after · data-gtw-auth="after" · closed → open = login + open; open → close = free.

Details after

Body

Aria toggles

#aria_before · data-gtw-auth="before" · aria-pressed="false" · false → true = login; true → false = free.

#aria_after · data-gtw-auth="after" · aria-pressed="false" · false → true = login + toggle; true → false = free.

#switch_before · data-gtw-auth="before" · aria-checked="false" (role="switch") · false → true = login; true → false = free.

#menu_before · data-gtw-auth="before" · aria-expanded="false" · closed → open = login; open → closed = free.

Click = focus (never gated)

#text_before / #textarea_before / #number_before · data-gtw-auth="before" · click = focus, no login; gate the submit button instead.

Activation click controls

#file_before · data-gtw-auth="before" · click → login (the picker opens only after auth).

#btn_before · data-gtw-auth="before" · click → login.

#submit_before · data-gtw-auth="before" · click → login; the form is not submitted.

#reset_before · data-gtw-auth="before" · reset = deactivation → no login; the reset runs.

Hidden and labels

#cb_hidden · data-gtw-auth-hidden="before" · checked initially · uncheck via the label = free; re-check = banner (no tab).

#for_label · data-gtw-auth="before" on the label[for] · #for_box checked · uncheck via the label = free; re-check = login.

#wrap_cb · data-gtw-auth="before" on the wrapper · #wcb · check → login; uncheck → free.
